# 初日 First Day

給大學生與剛出社會的新鮮人的生活指南網站原型，涵蓋食、衣、住、行、育、樂與財務七大主題。

## 預覽與部署

直接開啟 `index.html` 即可預覽。可推送此資料夾至 GitHub，再匯入 Vercel；選擇 **Other**，Build Command 留空，Output Directory 設為 `.`。

## 原型功能

- 響應式首頁、七大分類篩選與指南搜尋
- 生活安全問答累積代幣、會員方案展示（NT$50/月）
- 行程清單、主題與頭貼設定儲存在瀏覽器 localStorage
- 教學影片主題連至 YouTube 搜尋

登入、真實會員付款、跨裝置資料同步、完整指南逐篇內容與多人問答服務尚未串接後端。現有問答為安全知識小測驗，不具代幣消耗或完整文章解鎖交易；上線前需建置身分驗證、資料庫、權限與金流服務。
